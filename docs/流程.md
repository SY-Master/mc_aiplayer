## "帮我收集原木" 全链路

### 第一步：你说的话 → LLM 决策

```
你: @Bob 帮我收集一些原木
  │
  ▼
ChatCaptureListener 解析 "@Bob 帮我收集一些原木"
  → BrainCoordinator.handleMessage(bot, "你", "帮我收集一些原木")
    → 构建 ChatMessage.user("[" + 你 + "] says: 帮我收集一些原木\n\nCurrent state:\n" + 感知快照JSON)
    → 提交给 DeepSeek API
```

### 第二步：LLM 返回 Tool Call

```
DeepSeek 看到: 附近有橡树(highlights 里有 nearest_tree), 背包空
DeepSeek 返回:
  content: "好的，我去收集一些原木。"          ← 广播到聊天栏 "<Bob> 好的，我去收集一些原木。"
  toolCalls: [{
    name: "assign_task",
    arguments: {"task_type":"gather", "params":{"item":"minecraft:oak_log", "count":16}}
  }]
```

### 第三步：Tool 调度 → 创建 Task

```
ActionDispatcher.dispatchBatch()
  → ToolRegistry 匹配 "assign_task"
    → createTask(bot, "gather", {"item":"minecraft:oak_log","count":16})
      → new GatherQuotaTask(Items.OAK_LOG, 16)
        → acceptItems = 全部原木族 (oak/spruce/birch/jungle/acacia/dark_oak/cherry/mangrove 等)
        → harvestBlocks = 对应的原木方块
```

### 第四步：TaskManager 分配

```
TaskManager.assign(bot, gatherTask, LLM_TOOL origin)
  → 先 abort 当前任务 (如果有)
  → task.start(bot)
    → onStart(): countSoFar=当前背包里已有原木数, phase=SURVEY
  → BotReporter 广播: "[Bob] 开始采集橡木原木。"
```

### 第五步：每 tick 执行（核心状态机）

```
┌──────────────────────────────────────────────────────────┐
│ SURVEY — 扫描周围找树                                      │
│   searchRadius 从 16→32→48 渐进扩大                        │
│   HarvestCore.nearestReachableBlock() 找最近可达原木         │
│   ├── 找到且直接够到 → startHarvest → HARVEST               │
│   ├── 找到但需走过去 → A* 寻路 → GOTO                        │
│   └── 48格找不到:                                          │
│       ├── 在地下? → trySurface(bot) 上浮到地表               │
│       ├── prospectAndApproach() 大范围96格扫描               │
│       └── escapeBarrenArea() 换片:                          │
│           ├── roamToNewArea() 28格横移换片 (最多8次)         │
│           └── startExplore() 大步定向远逃 (48/40/32格,8跳)   │
├──────────────────────────────────────────────────────────┤
│ GOTO — 走向目标树                                          │
│   A* 导航到树的落脚点                                       │
│   到达(canReach)→ startHarvest → HARVEST                   │
│   走不到:                                                  │
│     → tryDigApproach() 挖掘接近(崖壁/高差树)                 │
│     → 连续2次同目标走崩 → 拉黑(TTL后复活) → 回SURVEY换树     │
│     → 坐标连续80t不动 → 悬空卡死兜底 → 强制脱困回SURVEY       │
├──────────────────────────────────────────────────────────┤
│ HARVEST — 砍树                                            │
│   HarvestCore.startMining(bot, targetPos) 开始挖掘          │
│   BlockMiner 每 tick 推进破块进度                           │
│   目标方块消失(空气/掉落) → PICKUP                          │
├──────────────────────────────────────────────────────────┤
│ PICKUP — 捡掉落物                                          │
│   forcePickupNearbyAnyOf(bot, acceptItems) 就近拾取         │
│   countSoFar 增长 →                                         │
│     够了 → DONE → complete()                                │
│     不够 → SURVEY 找下一棵                                  │
│   5棵连续采到但捡不到 → roamToNewArea 换片                   │
│   累计捡不到 + 换片也不行 → fail("pickup_timeout")           │
├──────────────────────────────────────────────────────────┤
│ DEPOSIT — 背包满存箱                                       │
│   内联 StockpileTask 把物品就近存入 base 旁箱子              │
│   存完 → 回 SURVEY 继续采                                   │
├──────────────────────────────────────────────────────────┤
│ 安全网(全程并行)                                            │
│   SurvivalGuard: 每 tick 前置熔断(溺水/岩浆/着火→abort)     │
│   DangerWatcher: 敌/饿/夜抢占(EatTask/CombatTask/EvadeTask)│
│   StuckWatcher: 本任务 isWaiting=true 豁免(自有看门狗)       │
│     自有看门狗: 160t没采到新木 → escapeBarrenArea 换片       │
│     6000t 总量超时 → fail("gather_timeout")                 │
└──────────────────────────────────────────────────────────┘
```

### 第六步：完成

```
16根原木到手 → countSoFar >= targetCount → phase=DONE → complete()
  → TaskManager 检测 COMPLETED → 移除活跃任务
  → BotReporter 广播: "[Bob] 完成了:采集橡木原木。"
  → GoalExecutor (如果有Goal上下文) 自动推进下一步
  → BrainCoordinator 自动唤醒 → LLM say "已经收集够16根原木了，还有什么需要吗？"
```

### 自愈设计：这个 Task 为什么不会卡死

| 问题场景 | 自愈机制 |
|---|---|
| 近处没树(无树高原) | 半径16→32→48渐进扩大 → prospect 96格 → roam 换片28格 → explore 大步逃出160格 |
| 树在崖壁够不到 | tryDigApproach 挖掘接近 → 挖不过去则拉黑换树(TTL后复活) |
| 砍完捡不到掉落物 | 连续5棵捡不到 → roam 换片，避免在一棵树上死磕 |
| 背包满了 | 内联 StockpileTask 自动存箱 |
| 淹水 | GOTO期间沾水→立刻弃目标+拉黑+NavSafetyNet拖上岸+干地重选 |
| 长时间没产出 | 自有看门狗 160t → escapeBarrenArea，不等 StuckWatcher 粗粒度 abort |
| 全局超时 | 6000t(5分钟)→fail，不无限循环 |
